# RDQ 已確認需求規格卡

- **使用者確認原文：**「延續 A＋B；技術選 G-A；鏡頭採斜俯視跟隨；敵人先只攻核心；追加 P1-04、P1-09。」
- **對象／風格：** 桌機與手機同等重要；低多邊形科幻。
- **技術：** G-A＝Three.js＋Vite＋Blender，延用現有模型與 MK2 槍械母檔。
- **A 範圍：** P0-02 桌機／多指觸控、P0-03 載入恢復、P0-04 可走動人物及主要障礙碰撞、P0-05 完整流程回歸；P0-01 時間一致性持續回歸。
- **B 範圍：** P1-01 隨角色射擊、射程、遮擋、分型準星與回饋；P1-06 待機／走跑動畫與腳步；P1-10 可略過及重看的教學、手機提示與無聲警告。
- **追加：** P1-04 低中高畫質、靜態合併、特效重用與量測；P1-09 準備階段自動存檔、續玩入口、格式驗證及損毀處理。

- **驗收：** 正常規則 10 波、勝敗重開、多指移動射擊及取消、手機橫直向、存檔往返／版本錯誤、模型故障恢復、同場景畫質量測。
